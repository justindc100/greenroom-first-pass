# Greenroom iOS host smoke

Disposable, Greenroom-owned native iOS fixture plus a no-model smoke workflow (`.github/workflows/ios-host-smoke.yml`, dispatched by hand). It measures how often and how long the hosted macos-26 simulator's display-capture and accessibility paths stall on the 0.3.13 preparation path, using the runner bundle published (untrusted, unpinned) from the private repository at the commit the workflow names: since 2026-09-09 the rounds run through the bundle's own iOS adapter (`ios-smoke`, with its post-open settle gate and RUNNER_BUSY recovery) after `sudo mdutil -a -i off`; `--driver raw` keeps the 2026-09-09 baseline of plain agent-device CLI calls. No model is called, no Greenroom run is minted, nothing talks to the control plane, and no customer code or credentials are present. Findings are recorded on Greenroom issue GR-12.
